# Speed Rovers 2 1.0.6

Continuous relative thumb steering alongside quick flicks. The touch begins at the current steering position to avoid jumps; 180 reference pixels move one lane. Release preserves fractional position. Bounds of +/-1.32 leave room for the bike footprint inside the road. One finger owns steering; HUD and letterbox touches are excluded. Focus loss, cancellation, pause and new races clear ownership. Mouse drag supports desktop verification.

Validation: gameplay checks cover fractional dragging, release, swipe, both bounds and HUD exclusion. Physical iPhone feel still needs user validation.
