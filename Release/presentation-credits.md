# Presentation assets

- Rajdhani Bold and Medium: Copyright 2014 Indian Type Foundry. SIL Open Font License 1.1, bundled in `Assets/Resources/Interface/Fonts/OFL.txt`. Source: https://github.com/google/fonts/tree/main/ofl/rajdhani
- Home showroom, rider gallery and city gallery: original built-in image generation. Prompts and revisions are recorded alongside this file. Final home uses `presentation-motorsport-prompt.json`; final riders use `presentation-family-prompts.json`; cities use `presentation-art-prompts.json`.
- UI tap, navigation and reward sounds: original procedural synthesis in `SpeedRoversPremiumUI.cs`.
- Visual reference for hierarchy and composition: Gameloft's published Asphalt Legends Unite interface and Dan Pratt's Need for Speed Unbound portfolio. No game logos, screenshots, vehicle models, interface assets or audio were copied into the app.

Downtown buildings and asphalt: original built-in image_gen assets. Prompts recorded in city-slice-art-prompts.json. Sprite bounds were measured from alpha without editing image pixels.
